Overview

This project targets a horror gameplay loop where enemy decisions build tension through searching, tracking, and adaptive behavior. It is being developed for Themed Horror Game Jam #21.

My Role

I am responsible for implementing core AI behavior in C++, including blackboard state management, perception handling, and integration of custom EQS query logic inside Unreal Engine.

Key Features

  • Two enemy archetypes with distinct pursuit and reaction patterns.
  • Behavior tree orchestration with utility-like decision priorities.
  • C++-driven perception, query evaluation, and combat-state transitions.
  • Level-context decision support through EQS-driven environment checks.
