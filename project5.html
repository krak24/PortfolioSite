Bird Flock Simulation

A simulation prototype focused on emergent flock movement in Unity.

Prototype
  • Unity
  • C#
  • Simulation

Overview

This project implements flocking behavior to simulate natural group movement. It applies local rule sets and tuning parameters to produce stable and believable flight patterns.

My Role

I implemented the simulation logic, tuned movement parameters, and tested behavior consistency across multiple scene setups.

Key Features

  • Rule-based flock movement using neighborhood-driven steering.
  • Balanced alignment, cohesion, and separation behavior tuning.
  • Parameter iteration for smooth and stable swarm motion.

Technologies Used

  • C#
