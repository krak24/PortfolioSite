Overview

This project explores core action-combat mechanics inspired by Sekiro, with emphasis on precision, readability, and player feedback consistency.

My Role

I implemented combat timing, parry handling, stance interactions, and animation transition logic. I also designed a reference diagram to map character states and behavior transitions before implementation.

Key Features

  • Parry windows and posture-style pressure interactions.
  • Animation frame-aware behavior logic for combat response timing.
  • Movement queueing to keep controls responsive during chained actions.
  • Diagram-driven architecture to validate state-transition design before coding.

Technologies Used

  • Animation System
  • State Logic
