Overview

This project recreates classic Arkanoid gameplay where the player controls a paddle and clears level layouts by bouncing a ball into destructible blocks.

My Role

I implemented gameplay flow, level structure, score progression, and the core user interface needed for complete play loops.

Key Features

  • Multi-level progression with varying block durability and point values.
  • Paddle-and-ball gameplay system with arcade pacing.
  • Score display and core menu/UI elements for a complete game loop.
