Overview

This project began from a terrain-generation tutorial and evolved into a custom island generation system with AI-oriented navigation support.

My Role

I extended the baseline generator, implemented chunk-level optimizations, and added gameplay-side systems such as spawner objectives and team-based enemy behavior.

Key Features

  • Perlin noise heightmap generation with terrain coloring by elevation bands.
  • LOD-aware terrain chunks for scalable runtime performance.
  • Chunk-adaptive NavMesh construction to reduce unnecessary pathing cost.
  • Objective-style enemy spawner placement on generated maps.
