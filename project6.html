Game Jam

Overview

This jam project is a 2D arena brawler where the player survives enemy waves and builds score through efficient combat.

My Role

I implemented the player character logic, integrated artist-provided animations, and built both the scoring and combo-rating systems.

Key Features

  • Combo ranking from C to S based on active combat performance.
  • Health-sacrifice mechanic where attacking costs health but successful hits restore it.
  • Wave-based enemy pressure to support high-tempo gameplay.

Technologies Used
