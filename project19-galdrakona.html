Overview

Galdrakona is an Unreal Engine project created during a month-long game jam. The team was larger than typical jam projects, and the production used Perforce for source control. This gave me practical experience working in a more structured collaborative environment with shared assets, task coordination, and integration dependencies.

My work focused on AI gameplay systems, specifically on tools and logic that allowed designers to place and manage enemies on the level using anchor-based navigation and behavior management.

My Role

I was responsible for AI programming. I implemented C++ management scripts and supporting Blueprint logic for enemy navigation, anchor-based placement, and group behavior coordination.

The AI systems were built based on design direction and documentation prepared by the project lead. My task was to translate those requirements into working Unreal Engine systems that could support enemy placement and allow the design to be iterated during production. I also contributed smaller bug fixes and general technical support where needed.

Key Features

  • Anchor-based enemy placement and navigation system designed for use by level designers.
  • AI behavior logic for arranging enemies around the player during encounters.
  • Work-in-progress combat behavior where enemies position around the player and attack in a controlled random pattern.
  • C++ AI management scripts with supporting Unreal Engine Blueprint logic.
  • Team production using Perforce in a larger jam environment.
