Overview

This project was developed during a 48-hour game jam and centers on puzzle-solving through dynamic level-state changes.

My Role

I implemented gameplay interactions, puzzle logic flow, and the audio layer using FMOD, while integrating custom art created for the game.

Key Features

  • Environmental puzzle mechanics where object repositioning changes level traversal.
  • Nine designed puzzle levels built for escalating complexity.
  • Integrated custom visual assets and FMOD-based audio pipeline.
