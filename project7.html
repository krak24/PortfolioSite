Finite State Machine AI Archer Prototype

A third-person combat prototype with FSM-driven enemy behavior in Unity.

Prototype
  • Unity
  • C#
  • Finite State Machine
  • NavMesh

Overview

This project explores ranged-combat gameplay in a third-person setup while testing AI state transitions between patrol, wait, and attack.

My Role

I implemented combat functionality for the player character, integrated animation workflows, and developed enemy AI movement and behavior logic.

Key Features

  • Finite state machine AI loop with patrol, wait, and attack states.
  • Unity NavMesh-based pathing and encounter behavior transitions.
  • Bow combat interaction with damage and health management.
  • Animation integration aligned with state and action timing.

Technologies Used

  • Unity
  • C#
  • FSM
  • NavMesh
  • Mixamo Animation
