Overview

This project compares two AI approaches in one environment. A wolf character is controlled by Utility AI, while a cat uses a Behavior Tree model.

My Role

I designed and implemented the behavior architecture, prioritized readability of decision logic, and set up practical state/data structures for iterative tuning.

Key Features

  • Utility AI need-management loop for hunger, thirst, and sleep behavior.
  • Behavior Tree-driven task pipeline for deterministic behavior sequencing.
  • Shared environment for comparing reactive and structured AI strategies.
  • Readable Blueprint organization for maintainable gameplay tuning.
