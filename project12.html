Tank with AI and Turret in Unreal Engine

A C++ gameplay and AI prototype developed as part of university coursework.

Prototype
  • Unreal Engine
  • C++

Overview

This project focuses on combining player vehicle controls with enemy AI behavior and autonomous turret combat logic.

My Role

I implemented player tank controls in C++, programmed turret targeting and firing behavior, and set up enemy behavior patterns using behavior trees.

Key Features

  • C++ vehicle movement and interaction logic for the player tank.
  • Autonomous turret detection and attack behavior.
  • Behavior Tree enemy loop with approach, deploy, retreat, and resupply flow.

Technologies Used

  • Unreal Engine
  • C++
  • Behavior Trees
  • Gameplay Programming
